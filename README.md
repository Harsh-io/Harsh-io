### 🔍 PR Review Multi-Agent System

A multi-agent AI system that automatically reviews GitHub Pull Requests from multiple perspectives.

**Key Features:**

* 🤖 Specialized AI agents for security, performance, documentation and code quality
* 🧠 RAG-based codebase context retrieval
* 🌳 Tree-sitter based code parsing
* 🔗 LangGraph agent orchestration
* ⚡ FastAPI backend
* 🐙 GitHub Webhooks & GitHub Actions
* 💬 Automated structured inline PR comments

🔗 **Project:** https://tinyurl.com/pr-review

### 🛰️ GeoRoute AI

An automated geospatial routing pipeline designed for large-scale infrastructure route analysis.

**Key Features:**

* 🛰️ Sentinel-2 satellite imagery
* 🌍 Microsoft Planetary Computer
* 🧠 SAM-Geo & Mask R-CNN obstacle detection
* 🗺️ OSMnx-based geospatial analysis
* 📊 Top-3 cost-based route generation
* ⚡ FastAPI + Docker + Airflow pipeline
* 🧭 Dijkstra-based routing engine

🔗 **Project:** https://tinyurl.com/georoute-ai

### 🎙️ EVA Speak AI Speaking Coach

An AI-powered speaking and interview practice platform that provides visual and verbal feedback.

**Key Features:**

* 🎤 Pronunciation and speech analysis
* 🗣️ Filler word, pause and repetition detection
* 📈 Speech-rate analysis
* 👁️ Eye-contact and face-direction analysis
* 📄 Resume-based interview preparation
* 🤖 AI-generated interview questions
* 📊 Progress tracking and user profiles

🔗 **Live Project:** https://eva-speak.vercel.app
